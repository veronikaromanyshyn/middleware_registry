# Middleware Deployment Registry
# Опис проєкту

Middleware Deployment Registry — вебдодаток для ведення реєстру порівняльного розгортання робототехнічних middleware на серверах та робочих станціях.

Проєкт розроблено в межах виробничої практики Центру інноваційного розвитку ІФНТУНГ.

Система дозволяє документувати результати встановлення, налаштування та запуску різних open-source middleware, таких як ROS2, micro-ROS, YARP та інших робототехнічних платформ.

---

# Предметна область
Предметною областю проєкту є робототехнічні middleware та програмні платформи для робототехніки й кіберфізичних систем.

Система використовується для накопичення інформації про встановлення middleware, порівняння результатів запуску та оцінювання їх придатності для навчального використання.

---

## Основні функції системи
* додавання нового запису;
* перегляд усіх записів;
* перегляд детальної інформації про запис;
* редагування запису;
* видалення запису;
* фільтрація записів за назвою системи;
* фільтрація записів за цільовою платформою;
* фільтрація записів за статусом запуску;
* завантаження логотипу системи;
* завантаження скріншота встановлення;
* завантаження скріншота запуску;
* завантаження скріншота демонстраційного прикладу;
* оцінювання придатності middleware за п'ятизірковою шкалою;
* збереження даних у базі даних SQLite.

## Інструкція локального запуску

### 1. Клонування репозиторію

```bash
git clone https://github.com/veronikaromanyshyn/middleware_registry.git
```

### 2. Перехід до каталогу проєкту

```bash
cd middleware_registry
```

### 3. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 4. Створення бази даних

```bash
python database.py
```

### 5. Запуск вебдодатка

```bash
python app.py
```

### 6. Відкриття системи у браузері

```text
http://127.0.0.1:5000
```

# # База даних

У проєкті використовується SQLite.

Файл бази даних:

```text
registry.db
```

Основна таблиця:

```text
deployment_records
```

Поля таблиці:

* id
* system_name
* version
* target_device
* installation_method
* demo_example
* dependencies
* launch_result
* problems
* educational_value
* status
* logo_image
* installation_image
* launch_image
* demo_image

---

## Тестові дані

Для демонстрації роботи системи можуть використовуватися записи про:

* ROS2 Humble
* ROS2 Jazzy
* micro-ROS
* YARP
* Gazebo
* Webots

Авторизація у системі не реалізована, тому тестові облікові записи відсутні.
